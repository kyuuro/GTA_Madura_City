# GTA: Gak Tau Aturan — Suramadu City

> **What if GTA VI took place in Surabaya and Madura?**
>
> A fan-made parody project inspired by GTA VI, featuring Surabaya, Jembatan Suramadu, and Madura.
>
> Made for fun. Updated whenever I'm bored enough to work on it.

## 🌴 About

**GTA: Gak Tau Aturan — Suramadu City** is a personal hobby project that brings open-world chaos to a familiar corner of Indonesia. 

NGL -- This Project is Fully Made using Claude.ai as the main coder, and suno.ai as the music, while the assets are downloaded from sketchfab and such (is included in credits.md)

Imagine driving through Surabaya, cruising across the Suramadu Bridge, getting lost in a Madura village, stealing a vehicle, and somehow ending up chased by Satpol PP.

It's a parody of the Grand Theft Auto formula, mixed with Indonesian locations, local atmosphere, and a healthy amount of nonsense.

This project is made purely for fun. Development only continues when I have spare time, feel like experimenting, or suddenly get another ridiculous idea.
Feel free to pull, modify the games, and launch your own, just don't forget to credit me.

No deadlines. No promises. Just vibes.

## 🎮 Features

- **3D Open World** — Explore a browser-based world built with Three.js.
- **Surabaya City** — Roads, buildings, neighborhoods, traffic, and urban scenery inspired by Surabaya.
- **Suramadu Bridge** — Cross the bridge connecting Surabaya and Madura.
- **Madura** — Explore a quieter area across the bridge, featuring village scenery.
- **Vehicles** — Drive cars, motorcycles, and angkot.
- **Vehicle Hijacking** — Walk up to a nearby vehicle and take it for a ride.
- **Living Traffic** — AI-controlled vehicles and pedestrians populate the world.
- **Wanted System** — Cause trouble and attract the attention of patrolling Satpol PP.
- **Police Pursuits** — Get chased, escape, or get caught and pay the consequences.
- **Traffic Lights** — Intersections have traffic signals. Whether you obey them is another story.
- **Vehicle Damage** — Crash too much and your vehicle might not survive.
- **Repair Shops** — Get your damaged vehicle repaired at designated locations.
- **Day & Night Cycle** — Experience changing lighting and vehicle headlights after dark.
- **Sound Effects** — Horns, sirens, and collision sounds.
- **Music** — Original tracks created for the project.
- **Mobile Controls** — Play using on-screen touchscreen controls.

*Features are experimental and may change, break, or disappear as development continues.*

## 🕹️ How to Play

### Run Locally

The game runs in a web browser.

1. Clone or download this repository.
2. Open a terminal in the project directory containing `index.html`.
3. Start a local HTTP server:

   ```bash
   python -m http.server 8000
   ```

4. Open the following address in your browser:

   http://localhost:8000

A local server is recommended for loading the game's JavaScript modules and 3D assets.

### Controls — PC

| Action | Control |
|---|---|
| Move | `W` `A` `S` `D` |
| Run / Turbo | `Shift` |
| Enter a vehicle | `F` |
| Honk | `H` |
| Toggle sound | `M` |
| Accelerate while driving | `W` |
| Steer while driving | `A` / `D` |

On mobile, use the on-screen controls.
