## API modul
- suramadu.js: `createSuramadu(scene,{height,night}) -> {heightAt(x,z), colliders(c), update(t)}`; main.js memakai bridge.heightAt untuk Y & blok air
- districts.js: `ZONES`, `inZone(x,z,pad)`, `shoreZ(heightFn,x)`, `seededRand(seed)`
- perak/kenjeran/kampung: `createX(scene,{height,roads,collider,quality}) -> {colliders(collider), update(t,dt)}` (kampung juga `upgradePoles()` async); roads.lines = [{hw,pts}]
- roads.js: `createRoads(scene, heightFn) -> {group, clearance(x,z), update(night)}`; data di roaddata.js (`ROADS`)
- buildings.js: `createBuildings(scene, {quality, height, roads, collider, night}) -> {group, count, list, cell, upgrade() async, update(x,z), dispose()}`; `planCity(o) -> {B,R,cell}` (murni, tanpa three)
- paving.js: `planPaving(buildings, {roads,collider,height,cell}) -> {strips}` (murni), `pavingIndex(strips) -> near(x,z,m)`, `createPaving(scene,{quality,height,roads,collider,houses,cell}) -> {group, near, count, strips, tris, update(x,z), dispose()}`
- character.js: `makeCharacter(opts)`, `animateCharacter(c, dt, moveSpeed)` (cari bagian via nama armL/armR/legL/legR/body), `SKINS`
- controls.js: `createControls() -> {x,y,run,yaw,update(dt)}`
- collide.js: `createCollider() -> {clear, add(x,z,hw,hd), resolve({x,z}, r)}` (tanpa three)
